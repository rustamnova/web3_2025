
# Bank Reviews — Baseline ML Outputs for Dashboard/DB

This package includes baseline, **database-ready** artifacts produced from the uploaded dataset (`reviews_combined_dedup.csv`), filtered to 2024-01-01 .. 2025-05-31. Topics are assigned via a fast **rule-based multilabel** approach (regexes), and **sentiment** is inferred from the numeric `rating` column (1–2=neg, 3=neu, 4–5=pos).

## Files
- `review_topics.csv` — **(review_id, topic)** with metadata
- `topics_overview.csv` — topics with counts and sentiment distribution (for topic list / cards)
- `topic_monthly.csv` — monthly time series per topic (for stacked bars / area charts)
- `global_monthly.csv` — global monthly sentiment
- `topic_regexes.json` — dictionary of topic → regex (baseline classifier)

## Schemas

### review_topics.csv
- `review_id` (string) — stable key from source dataset
- `topic` (string) — topic slug
- `published_at` (UTC ISO) — original publish timestamp
- `month` (YYYY-MM) — month bucket
- `source` (string) — source site
- `rating` (float) — 1..5, as in source
- `sentiment` (enum) — {neg, neu, pos, unknown} derived from rating

### topics_overview.csv
- `topic` (string) — topic slug
- `label` (string) — human-friendly label (autogenerated from keywords)
- `keywords` (string) — top tokens (1-2grams) per topic for context
- `n_rows` (int) — total rows tagged with the topic (multilabel)
- `n_reviews` (int) — unique reviews that mention the topic
- `share_%` (float) — share of topic rows among all topic rows
- `pos`, `neu`, `neg`, `unknown` (int) — counts
- `pos_share_%`, `neu_share_%`, `neg_share_%` — within-topic sentiment shares

### topic_monthly.csv
- `topic` (string), `month` (YYYY-MM)
- `n`, `pos`, `neu`, `neg`, `unknown` (int)
- `pos_share_%`, `neu_share_%`, `neg_share_%` (float)

### global_monthly.csv
- `month` (YYYY-MM)
- `n`, `pos`, `neu`, `neg`, `unknown` (int)
- `pos_share_%`, `neu_share_%`, `neg_share_%` (float)

## Notes
- This is a pragmatic baseline to **unblock DB ingestion and dashboard wiring**. You can map topics to UI sections and build charts without waiting for the final ML model.
- When the ML classifier is ready (BERTopic/transformer multi-label), it can **drop-in replace** the `review_topics.csv` by keeping the same schema.
- The topic regexes in `topic_regexes.json` can be used server-side for **fallback classification** if the ML endpoint is unavailable.
