## Архитектура NaviMind (MVP)

### Компоненты
- API (FastAPI): эндпоинты `/health`, `/topics`, `/predict`, `/feedback`.
- Модули инференса: `Embedder`, `MultiLabelClassifier`, `SentimentModel` (заглушки, подменяются на прод моделі: ONNX/torch).
- Конфигурация: `app/config.py` (DSN внешних сервисов, лимиты).
- Инфраструктура (dev): Postgres, ClickHouse, Redis, RabbitMQ через Docker Compose.

### Потоки данных
1) Запрос `/predict` принимает батч отзывов (до `BATCH_LIMIT`).
2) Эмбеддинг → мультилейбл классификация тем → аспектная тональность.
3) Возврат массива предсказаний, лог метрик (размер, длительность).
4) `/feedback` принимает ручную разметку; в MVP — лог, далее — запись в БД/очередь.
