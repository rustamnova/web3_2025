# NaviMind — Сервис анализа отзывов по темам и тональности

## 1. Описание решения

### Краткое описание функционала сервиса и его назначения

**NaviMind** — это интеллектуальный сервис для анализа банковских отзывов, который автоматически определяет тематику и эмоциональную тональность клиентских отзывов. Сервис предназначен для:

- **Автоматической категоризации** отзывов по 20+ темам (мобильное приложение, обслуживание в отделении, кредитные продукты и др.)
- **Анализа тональности** с определением положительных, отрицательных и нейтральных оценок
- **Масштабируемой обработки** больших объемов данных (до 50,000 отзывов за раз)
- **Визуализации результатов** через интерактивный веб-интерфейс в стиле Газпромбанка
- **Интеграции с внешними источниками** (banki.ru, sravni.ru) для автоматического парсинга отзывов

### Основные возможности:
- 🔍 **Парсинг отзывов** с популярных банковских сайтов
- 📊 **Многоуровневый анализ** тем и тональности
- 📈 **Интерактивный дашборд** с визуализацией метрик
- 🗄️ **Управление данными** через файловую загрузку (CSV, JSON, TXT)
- 🔧 **API для интеграции** с внешними системами
- 📱 **Адаптивный интерфейс** для всех устройств

## 3. Методы и подходы к предобработке данных и построению моделей

### Предобработка данных

#### 3.1 Очистка текста
```python
def preprocess_text(text: str) -> str:
    """Комплексная предобработка текста отзывов"""
    # Удаление HTML тегов
    text = re.sub(r'<[^>]+>', '', text)
    
    # Нормализация пробелов
    text = re.sub(r'\s+', ' ', text)
    
    # Удаление специальных символов
    text = re.sub(r'[^\w\s.,!?]', '', text)
    
    # Приведение к нижнему регистру
    text = text.lower().strip()
    
    return text
```

#### 3.2 Токенизация и нормализация
- **Лемматизация** - приведение слов к базовой форме
- **Удаление стоп-слов** - фильтрация служебных слов
- **Обработка сокращений** - расшифровка банковских терминов
- **Нормализация чисел** - унификация числовых значений

#### 3.3 Векторизация текста
- **TF-IDF** - для базовой классификации тем
- **Word2Vec** - для семантического анализа
- **BERT embeddings** - для контекстуального понимания
- **Feature engineering** - создание дополнительных признаков

### Модели машинного обучения

#### 3.4 Классификация тем (Topic Classification)

**Многоуровневая архитектура:**
```
Input Text → Preprocessing → Feature Extraction → Classification

```

**Алгоритмы:**
- **Random Forest** - для базовой классификации
- **SVM** - для линейно разделимых классов
- **Neural Networks** - для сложных паттернов
- **Ensemble Methods** - комбинация нескольких моделей

#### 3.5 Анализ тональности (Sentiment Analysis)

**Трехклассовая классификация:**
- **Положительная** - положительные отзывы
- **Отрицательная** - критичные отзывы  
- **Нейтральная** - нейтральные высказывания

**Подходы:**
```python
def analyze_sentiment(text: str) -> Dict[str, float]:
    """Анализ тональности с использованием нескольких методов"""
    
    # 1. Rule-based подход
    sentiment_score = rule_based_analysis(text)
    
    # 2. ML модель
    ml_score = ml_model.predict_proba(text)
    
    # 3. Deep Learning
    dl_score = bert_model.predict(text)
    
    # Ensemble
    final_score = ensemble_vote([sentiment_score, ml_score, dl_score])
    
    return final_score
```

#### 3.6 Временной анализ (Time Series Analysis)

**Помесячная динамика:**
- **Тренды тональности** - изменение настроений во времени

- **Аномалии** - выявление необычных событий
- **Прогнозирование** - предсказание будущих трендов
